# Архитектурные решения

Этот документ фиксирует ключевые решения, принятые при разработке библиотеки.
Обновляйте его при изменении архитектуры.

## Общие положения

1. **STL-совместимость.** Интерфейсы и поведение должны максимально соответствовать 'std::'.
2. **C++20.**
3. Заголовочные файлы обязаны иметь тип .hpp, а не .h, так как библиотека связана только с языком C++.
