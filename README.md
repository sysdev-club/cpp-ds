# C++ Data Structures

## Описание проекта

Учебный проект, реализующий 16 основных контейнеров из стандартной библиотеки C++20 - STL.
Главная цель проекта - получить углубленные знания о библиотеке STL, принятых в ней решениях, научиться принимать собственные решения и находить компромиссы при реализации непростых решений.

### Структура проекта

...
├── docs/               # Содержит техническое описание проекта
